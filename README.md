## 📁 Featured Projects

### 🔬 [VLSI Project: 3-Input OR Gate Design (45 nm)](https://github.com/drsarojshah/VLSI_OR-Gate_Design)
Designed, laid out, and simulated a CMOS OR gate using Cadence Virtuoso (gpdk045). Verified DRC, source/sink current, and timing response.

### 💻 [Master's Project: LEGv8 Processor Execution Engine](https://github.com/drsarojshah/masters-arm-datapath)
Simulated a 5-stage LEGv8 pipeline processor in C and synthesized to VHDL using Vitis HLS. Validated waveform and register/memory interaction.

### 🔧 [FPGA Project: ROM–ALU System (Vivado / Basys-3)](https://github.com/drsarojshah/fpga-rom-alu-system)
Designed and implemented a ROM–ALU datapath system on Basys-3 FPGA. Packaged custom VHDL into a reusable IP and built a full IPI block design in Vivado.

### 🧬 [ML Project: DNA Promoter Sequence Classification](https://github.com/drsarojshah/ML_DNA_Classification)
Classified E. coli DNA sequences using MATLAB with SVM, kNN, Naïve Bayes, and Neural Networks. Achieved 90%+ accuracy with Naïve Bayes classifier.
